# CH2C_Startopgave

En retro-arkade bygget med Next.js og TypeScript. Projektet indeholder spilbare versioner af Tetris, Pac-Man og Snake med både tastatur- og touchstyring.

## Start projektet

```bash
npm install
npm run dev
```

Åbn derefter `http://localhost:3000`.

## Styring

- Piletaster eller WASD bruges til bevægelse.
- I Tetris roterer pil-op, og mellemrum slipper brikken.
- Vælges mobil på forsiden, vises touchknapper under spillene.
